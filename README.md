# PollyGlot AI Translator

PollyGlot AI Translator is a lightweight web application that provides fast and smart text translation using AI.  
Users can type any message, choose a target language, and instantly receive a natural translation in a clean chat-style interface.

## Live Concept

A modern translator designed for speed, simplicity, and multilingual communication.

---

## Features

- 🌍 **100+ Supported Languages**  
  Translate text into a wide range of global languages.

- 🤖 **AI-Powered Translation**  
  Uses OpenAI API for accurate and context-aware translations.

- 💬 **Chat Interface**  
  User-friendly messaging layout for input and translated responses.

- 🌐 **Automatic Source Language Detection**  
  Detects the language of the entered text automatically.

- 🇸🇦 **Arabic RTL Support**  
  Automatically switches layout and font direction for Arabic text.

- 🎨 **Responsive Design**  
  Works smoothly on desktop and mobile devices.

- ⏳ **Loading State Feedback**  
  Shows loading animation while waiting for translation.

- 🔒 **Secure Translation Prompting**  
  Built with prompt protection to prevent misuse and keep translations focused.
